# What is SCSI2Pi?

SCSI2Pi is advanced SCSI/SASI device emulation software designed for the PiSCSI/RaSCSI board. It offers expanded and refined device emulations, higher transfer rates, significantly smaller binary sizes, new SCSI initiator mode tools, a SCSI-to-USB bridge and a <a href="https://www.scsi2pi.net/en/piscsi_comparison.html">wide array of new features</a>. SCSI2Pi is compatible with both the PiSCSI web UI and the <a href="https://www.scsi2pi.net/en/app.html">SCSI Control app</a> for Android.<br />
SCSI2Pi emulates hard drives, removable media drives, magneto-optical (MO) drives, CD-ROM drives, tape drives (streamers), printers, network adapters and a real-time clock. Features such as the SCSI-to-USB bridge and advanced streamer capabilities, including variable block sizes, navigation and filemarks, make SCSI2Pi an exceptionally versatile SCSI emulation platform. It allows you to easily connect a variety of devices to vintage systems, including classic Macs, Atari ST/TT/Falcon030 systems, Amigas, workstations, and samplers. Imagine using a USB flash drive with your 68K Mac or Atari, or booting a VAX workstation directly from an emulated tape drive!<br />
You can run SCSI2Pi as a standalone application or alongside the PiSCSI web interface. Transitioning from PiSCSI to SCSI2Pi takes just seconds: Simply install a <a href="https://www.scsi2pi.net/en/installation.html">Debian package containing the SCSI2Pi binaries</a>.

# Who am I?

Up until release 24.04.01, I was the <a href="https://www.scsi2pi.net/en/scsi2pi.html">primary contributor</a> to the PiSCSI SCSI emulation backend. During my time with the project, I overhauled the architecture, implemented a Protobuf-based remote client API, and re-engineered most of the legacy code using modern C++. In addition to introducing <a href="https://www.scsi2pi.net/en/scsi2pi.html">new features</a> and broadening platform compatibility, I fixed numerous bugs and built an extensive unit test suite.<br />
Within the PiSCSI project, there was limited interest in refactoring legacy code or leveraging the initiator mode capabilities of the FULLSPEC PiSCSI board. Long-promised features remained unaddressed, and the release cycle for new changes was slow. Consequently, I chose to improve the emulation in a separate project, while maintaining compatible with the PiSCSI web interface wherever possible. SCSI2Pi has since evolved rapidly, delivering a wealth of useful new features and expanding supported device types. In the meantime, some SCSI2Pi features have been backported to PiSCSI.<br />
I am also the author of the <a href="https://www.hddriver.net">HDDRIVER software package for Atari computers</a> and the <a href="https://www.scsi2pi.net/en/app.html">SCSI Control app</a> for Android, which serves as a remote control for PiSCSI/RaSCSI boards. SCSI Control seamlessly supports both SCSI2Pi and PiSCSI.
